Cara akses bucket S3 pake AWS CLI (studi kasus Nevacloud)

Download dan install AWS CLI

curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install

Konfigurasi

/usr/local/bin/aws configure

Nanti dia minta aws access key id sama aws secret access key

Cara dapetinnya ada di dashboard object storage Nevacloud

Cara ceknya:

febri@ubuntu:~$ cat ~/.aws/credentials
[default]
aws_access_key_id = XXX
aws_secret_access_key = XXX 
febri@ubuntu:~$

Tambahin ini:

nano ~/.aws/config

[default]
region = id-jkt-1
output = json

s3 =
    addressing_style = path
    signature_version = s3v4

Verifikasi

febri@ubuntu:~$ /usr/local/bin/aws --version
aws-cli/2.34.20 Python/3.14.3 Linux/6.14.0-37-generic exe/x86_64.ubuntu.25
febri@ubuntu:~$

Test:

febri@ubuntu:~$ /usr/local/bin/aws s3 ls --endpoint-url https://s3.nevaobjects.id --region id-jkt-1
2026-03-31 10:18:20 febnug-data
febri@ubuntu:~$

Upload file

febri@ubuntu:~$ AWS_REQUEST_CHECKSUM_CALCULATION=when_required \
AWS_RESPONSE_CHECKSUM_VALIDATION=when_required \
/usr/local/bin/aws s3 cp test-upload.txt s3://febnug-data/ \
--endpoint-url https://s3.nevaobjects.id \
--region id-jkt-1 \
--no-guess-mime-type
upload: ./test-upload.txt to s3://febnug-data/test-upload.txt 
febri@ubuntu:~$

Download file

febri@ubuntu:~/test$ AWS_REQUEST_CHECKSUM_CALCULATION=when_required \
AWS_RESPONSE_CHECKSUM_VALIDATION=when_required \
/usr/local/bin/aws s3 cp s3://febnug-data/test-upload.txt . \
--endpoint-url https://s3.nevaobjects.id \
--region id-jkt-1
download: s3://febnug-data/test-upload.txt to ./test-upload.txt
febri@ubuntu:~/test$ ls
test-upload.txt
febri@ubuntu:~/test$

Bikin bucket

febri@ubuntu:~$ /usr/local/bin/aws s3api create-bucket \
--bucket febnug-backup \
--endpoint-url https://s3.nevaobjects.id \
--region id-jkt-1
febri@ubuntu:~$

Itu pake API s3api

Bikin bucket jadi public

febri@ubuntu:~$ /usr/local/bin/aws s3api put-bucket-policy \
--bucket febnug-backup \
--policy '{
  "Version":"2012-10-17",
  "Statement":[{
    "Effect":"Allow",
    "Principal":"*",
    "Action":["s3:GetObject"],
    "Resource":["arn:aws:s3:::febnug-backup/*"]
  }]
}' \
--endpoint-url https://s3.nevaobjects.id \
--region id-jkt-1
febri@ubuntu:~$

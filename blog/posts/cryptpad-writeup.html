Binary

Di berikan file binary Win32 PE executable dan file flag.enc

cryptpad.exe: PE32 executable (GUI) Intel 80386, for MS Windows, 4 sections

Analysis

Analisis menggunakan metode static analysis, tools yang dipake IDA Pro Free

Setelah binary di load ke IDA, ada imports yang menarik:

  1. SystemFunction036 → ini adalah RtlGenRandom
  2. CreateFileA, WriteFile
  3. MSVCRT (fungsi C standar)

Ada string penting juga disini:

CryptPad 1.0 is an encrypted notepad that uses a custom encryption algorythm

Berarti:

  1. Ini custom crypto
  2. Bukan AES/OpenSSL langsung
  3. Kemungkinan XOR/stream cipher buatan sendiri

File flag.enc

Ukuran file 64 bytes

16 f6 b4 1c 00 00 00 e8 17 1b f4 50 3f 3d 70 08

Menariknya:

  1. Ada 00 00 00 e8
  2. Itu kemungkinan integer 0x000000e8 = 232
  3. Bisa jadi original length disimpan di footer

Strukturnya mungkin kek gini:

[ encrypted_data ]
[ original_length (4 bytes) ]
[ key / seed / checksum (8 bytes?) ]

Entry to Encryption Path

Flow dari GUI:

GetWindowTextA
→ sub_40166B (generate random)
→ sub_4014EB (encrypt)
→ WriteFile

Fungsi penting:

sub_4014EB(buffer, length, mode)

mode == 1 → encryption path.

Pre-Encryption XOR Layer

Bagian pertama:

mov esi, [ebp+arg_0]      ; buffer
mov edi, offset unk_4024C5 ; 8-byte key
mov ecx, NumberOfBytesWritten

loc_401558:
    xor edx, edx

loc_40155A:
    mov al, [esi]
    mov bl, [edi]
    xor al, bl
    mov [esi], al
    inc esi
    inc edi
    inc edx
    cmp edx, 8
    jz  loc_401558
    dec ecx
    jz  loc_40156F

Analisis

  • edi menunjuk ke unk_4024C5
  • Loop internal reset setiap 8 byte
  • Pattern jelas:

data[i] ^= key[i % 8]

Itu adalah fixed-length 8-byte repeating XOR.

Analisis

Itu textbook RC4 KSA:

j = 0;
for (i = 0; i < 256; i++) {
    j = j + S[i] + key[i];
    swap(S[i], S[j]);
}

  • bl → j
  • edi → S-box

i = 0;

for each byte:
    i++

    K = S[(S[i] + S[j]) & 0xFF]

Register mapping:

  • al → i

Stream byte:

Terus:

100% canonical RC4.

Post-XOR Layer

Abis RC4 selesai:

mov esi, buffer
mov edi, offset unk_4024C5
...
xor al, bl

Itu identik Pre-XOR.

Jadi total pipeline:

data = XOR8( RC4( XOR8(data) ) )

File Footer Structure

Bagian akhir fungsi:

mov [edi], eax              ; original_length
add edi, 4
mov ecx, 8
mov esi, offset unk_4024C5
rep movsb                   ; copy key
mov byte ptr [edi], 8

Struktur akhir file:

offset +0: encrypted data
...
offset -13: original_length (4 byte LE)
offset -9 : 8-byte key
offset -1 : 0x08

Total footer: 13 bytes.

Script Solver

Ini solver script python yang gw bikin

from Crypto.Cipher import ARC4

with open("flag.enc", "rb") as f:
    data = f.read()

# Extract footer
footer = data[-13:]
original_length = int.from_bytes(footer[:4], "little")
key = footer[4:12]

ciphertext = data[:-13]

# Step 1: XOR 8-byte key
def xor8(data, key):
    out = bytearray()
    for i in range(len(data)):
        out.append(data[i] ^ key[i % 8])
    return bytes(out)

step1 = xor8(ciphertext, key)

# Step 2: RC4 decrypt
rc4 = ARC4.new(key)
step2 = rc4.decrypt(step1)

# Step 3: XOR again
plaintext = xor8(step2, key)

print(plaintext[:original_length])

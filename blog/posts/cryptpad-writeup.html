CryptPad Handout (https://crackmesone.ctfd.io) writeup

Iseng main CTF crackmes one di https://crackmesone.ctfd.io

Binary

Di berikan file binary Win32 PE executable dan file flag.enc

cryptpad.exe: PE32 executable (GUI) Intel 80386, for MS Windows, 4 sections

Analysis

Analisis menggunakan metode static analysis, tools yang dipake IDA Pro Free

Setelah binary di load ke IDA, ada imports yang menarik:

  1. SystemFunction036 → ini adalah RtlGenRandom
  2. CreateFileA, WriteFile
  3. MSVCRT (fungsi C standar)

Ada string penting juga disini:

CryptPad 1.0 is an encrypted notepad that uses a custom encryption algorythm

Berarti:

  1. Ini custom crypto
  2. Bukan AES/OpenSSL langsung
  3. Kemungkinan XOR/stream cipher buatan sendiri

File flag.enc

Ukuran file 64 bytes

16 f6 b4 1c 00 00 00 e8 17 1b f4 50 3f 3d 70 08

Menariknya:

  1. Ada 00 00 00 e8
  2. Itu kemungkinan integer 0x000000e8 = 232
  3. Bisa jadi original length disimpan di footer

Strukturnya mungkin kek gini:

[ encrypted_data ]
[ original_length (4 bytes) ]
[ key / seed / checksum (8 bytes?) ]

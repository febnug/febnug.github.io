LOL, fake USB drive?

Jadi kasusnya gw beli USB drive atau flashdisk merk Toshiba 4GB sizenya, pas gw colokin kok sizenya aneh 64GB akhirnya gw penasaran buat ngoprek USB drive itu.

Check

Setelah flashdisk gw plug ke portnya, langsung gw cek pake lsblk, disini ke deteknya sdc

febri@ubuntu:~$ lsblk | grep sdc
sdc      8:32   1    64G  0 disk /media/febri/New Volume
febri@ubuntu:~$

Format ke NTFS

Gw kepikiran buat nge-format flashdisknya, terus gw ubah file systemnya ke NTFS

Un-mount dulu:

febri@ubuntu:~$ sudo umount /dev/sdc
[sudo] password for febri: 
febri@ubuntu:~$ lsblk | grep sdc
sdc      8:32   1    64G  0 disk 
febri@ubuntu:~$

Terus format/wipe:

febri@ubuntu:~$ sudo wipefs -a /dev/sdc
/dev/sdc: 8 bytes were erased at offset 0x00000003 (exfat): 45 58 46 41 54 20 20 20
febri@ubuntu:~$

Lanjut format:

febri@ubuntu:~$ sudo wipefs -a /dev/sdc
/dev/sdc: 8 bytes were erased at offset 0x00000003 (exfat): 45 58 46 41 54 20 20 20
febri@ubuntu:~$ sudo parted /dev/sdc mklabel msdos
Information: You may need to update /etc/fstab.

febri@ubuntu:~$ sudo parted -a optimal /dev/sdc mkpart primary ntfs 0% 100%
Information: You may need to update /etc/fstab.

febri@ubuntu:~$ sudo mkfs.ntfs -f /dev/sdc1                               
Cluster size has been automatically set to 4096 bytes.
Creating NTFS volume structures.
mkntfs completed successfully. Have a nice day.
febri@ubuntu:~$

Cek:

febri@ubuntu:~$ lsblk | grep sdc
sdc      8:32   1    64G  0 disk 
└─sdc1   8:33   1    64G  0 part 
febri@ubuntu:~$

Connect wifi pake iwctl di Arch Linux

Caranya

Ketik:

root:~# iwctl
NetworkConfigurationEnabled: enabled
StateDirectory: /var/lib/iwd
Version: 2.22
[iwd]#

List device

[iwd]# device list
                                    Devices                                   *
--------------------------------------------------------------------------------
  Name                  Address               Powered     Adapter     Mode
--------------------------------------------------------------------------------
  wlan0                 ce:28:8f:8f:6c:ad     on          phy0        station

Terminate
[iwd]#

Scan & show

[iwd]# station wlan0 scan
[iwd]# station wlan0 show

Get networks

[iwd]# station wlan0 get-networks

--------------------------------------------------------------------------------
      Network name                      Security            Signal

Connect

[iwd]# station wlan0 connect "Febri's Hostspot"

Misal gw mau konek ke SSID yang di atas, nanti biasanya tinggal masukin password, in case gw udah konek ke SSID itu

Contoh laen, gw mau konek ke Indihome_EXT

[iwd]# station wlan0 connect Indihome_EXT
Type the network passphrase for Indihome_EXT psk.
Terminate
Passphrase:

Nah, tinggal masukin passwordnya

Isu iwctl gak bisa konek ke google

Edit file konfigurasi /etc/iwd/main.conf jadi:

[General]
EnableNetworkConfiguration=true

Restart service iwd, systemctl restart iwd.service

Alt

Enable systemd-networkd

systemctl enable --now systemd-networkd.service

Bikin /etc/resolv.conf simbolik link ke systemd-resolved

ln -sf /run/systemd/resolve/stub-resolv.conf /etc/resolv.conf

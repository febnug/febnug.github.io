Install Jenkins di Arch Linux

Really fucker?

Add user

Contoh user febri

sudo useradd -m -s /bin/bash febri

Set password:

sudo passwd febri

Tambahin group ke wheel (sudo group)

sudo usermod -aG wheel febri

Cek, groups febri

Harusnya jadi gini, febri : febri wheel

Aktifin sudo untuk group wheel

Kalo belum install vi, install dulu:

sudo pacman -Sy vi

Baru, sudo visudo

Uncomment, %wheel ALL=(ALL:ALL) ALL

Test, su - febri, harusnya bisa masuk user febri

Install Jenkins

Update, sudo pacman -Syu

Install java, sudo pacman -S jdk17-openjdk

Kalo udah cek, java -version

Jenkins tidak ada di repo official Arch, jadi via AUR

Install yay dulu:

sudo pacman -S --needed base-devel git
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si

Install jenkins LTS:

yay -S jenkins-lts

Enable terus start jenkins

sudo systemctl enable jenkins
sudo systemctl start jenkins

Cek status, systemctl status jenkins

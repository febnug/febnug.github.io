RAID: Latihan bikin RAID 5 di Alpine Linux menggunakan QEMU

TLDR

Anggep udah install Alpine Linux yang terkoneksi internet pake Qemu tentunya cok

Bikin disk buat disk utama Alpine Linux

qemu-img create -f qcow2 alpine-linux.qcow2 4G

Bikin disk buat simulasi disk raid

qemu-img create -f qcow2 disk1.qcow2 1G
qemu-img create -f qcow2 disk2.qcow2 1G
qemu-img create -f qcow2 disk3.qcow2 1G

Run VM Alpine Linux

qemu-system-x86_64 \
  -m 512M \
  -boot d \
  -drive file=alpine-linux.qcow2,if=virtio \
  -drive file=disk1.qcow2,if=virtio \
  -drive file=disk2.qcow2,if=virtio \
  -drive file=disk3.qcow2,if=virtio \
  -drive file=disk4.qcow2,if=virtio \
  -device virtio-net,netdev=net0 \
  -netdev user,id=net0,hostfwd=tcp::2222-:22 \
  -nographic

Install mdadm

Di alpine linux install mdadm

apk update
apk add mdadm

lolcathost:~# cat /etc/mdadm.conf

Aktifkan mdadm auto-start saat boot

lolcathost:~# rc-update add mdadm boot
 * service mdadm added to runlevel boot
lolcathost:~# rc-service mdadm start
 * Starting mdadm ...
 [ ok ]
lolcathost:~#

Cek status:

lolcathost:~# rc-service mdadm status
 * status: started
lolcathost:~#

Test reboot

lolcathost:~# reboot

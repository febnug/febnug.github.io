Internal Trainer ELF, Shellcode Stub untuk Self-Memory Mutation di Linux x86-64

Kebanyakan trainer modern bekerja dengan cara memodifikasi memory proses lain. Teknik yang digunakan biasanya melibatkan API seperti ptrace, injection, atau manipulasi memory eksternal.

Tapi bagaimana kalau konsep trainer tersebut diperkecil menjadi sebuah ELF minimal yang hanya memodifikasi dirinya sendiri?

Artikel ini membahas eksperimen kecil tentang:

  • ELF minimal berbasis syscall Linux
  • Shellcode null-free
  • Self-memory mutation
  • Teknik jmp-call-pop
  • Ekstraksi shellcode menggunakan objcopy

Semua dilakukan tanpa libc, tanpa dynamic linker, dan tanpa proses eksternal.

Ide Dasar

Program memiliki string internal:

self-memory mutation: hp patched to 999

Huruf d berubah menjadi D secara langsung di memory runtime.

Kenapa Menarik?

Eksperimen seperti ini terlihat sederhana, tetapi sebenarnya menyentuh beberapa konsep penting dalam dunia shellcode modern:

  1. Position Independent Code (PIC)
  2. Self-referential payload
  3. Runtime memory mutation
  4. Null-byte avoidance
  5. Pure syscall execution
  6. Embedded data access

Teknik kecil seperti ini sering menjadi pondasi untuk:

  1. polymorphic shellcode
  2. self-decoding payload
  3. tiny loader
  4. staged payload
  5. runtime patching
  6. shellcode encoder

Teknik jmp-call-pop

Shellcode hampir selalu berjalan di alamat memory yang tidak diketahui.

Karena itu kita tidak bisa menulis:

mov rsi, 0x401000

Alamat tersebut belum tentu valid ketika payload dipindahkan.

Sebagai gantinya, shellcode klasik menggunakan teknik:

jmp -> call -> pop

Flow-nya:

jmp get_base
        |
        v
     call stub
        |
        v
   push RIP ke stack
        |
        v
      pop rsi

Dengan cara ini shellcode bisa mengetahui alamat datanya sendiri tanpa hardcoded pointer.

PoC NASM x86-64

Berikut PoCnya:

BITS 64
GLOBAL _start

SECTION .text

_start:
    jmp short get_base

stub:
    pop rsi

    ; ubah 'd' -> 'D'
    xor eax, eax
    mov al, 'D'

    mov [rsi + marker_offset], al

    ; write(1, msg, len)
    xor eax, eax
    mov al, 1

    xor edi, edi
    inc edi

    xor edx, edx
    mov dl, msg_len

    syscall

    ; exit(0)
    xor eax, eax
    mov al, 60

    xor edi, edi

    syscall

get_base:
    call stub

msg:
    db "self-memory mutation: hp patched to 999", 10

msg_len equ $ - msg
marker_offset equ 31

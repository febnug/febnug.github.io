Bikin VirtualHost di OpenBSD

By default, webserver di OpenBSD sudah terinstall, yaitu httpd, jadi langsung ngonfig aja

Edit /etc/httpd.conf

Edit, terus isi kek gini:

config httpd.conf 

server "example.com" {
    listen on * port 80
    root "/htdocs/example"
    directory index "index.html"
}

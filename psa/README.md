# PSA Landing Page

Static responsive landing page berdasarkan company profile PT Pantero Selaras Agung.

## Struktur
- `index.html`
- `css/style.css`
- `js/main.js`
- `assets/` gambar dari company profile

## Cara jalanin
Buka `index.html` langsung di browser, atau deploy ke GitHub Pages / Netlify / hosting static.

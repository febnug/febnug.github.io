Important note

RAID improves availability, but RAID is not a backup. A deleted file, ransomware, filesystem corruption, fire, theft, or controller bug can still destroy data. For important data, keep an offline or offsite backup.

RAID 0 - Striping

Recommendation: use 2 disks for basic speed testing; 3-4 disks for lab/demo performance scaling.

Why: every extra disk increases speed potential but also increases chance of total array loss.

Rule: if one disk dies, the array is broken.

RAID 1 - Mirroring

Recommendation: 2 disks for most cases. Add more mirror copies only for extra read availability.

Why: it is simple, easy to recover, and good for OS or small critical data volumes.

Rule: usable capacity equals the size of one disk.

RAID 5 - Single Parity

Recommendation: 3-6 disks for small NAS/lab arrays.

Why: it gives better capacity efficiency than RAID 1, but only survives one failed disk.

Rule: during rebuild, the array has no remaining parity safety.

RAID 6 - Dual Parity

Recommendation: 4-8 disks, especially with large HDDs.

Why: it can survive a second disk failure during rebuild.

Rule: write performance is usually lower than RAID 5 because two parity blocks must be updated.

RAID 10 - Mirror + Stripe

Recommendation: 4+ disks, always even disk count.

Why: it combines good performance with safer and faster rebuilds than parity RAID.

Rule: it survives failures as long as no mirror pair loses both disks.

RAID 01 - Stripe + Mirror

Recommendation: use only as a learning comparison.

Why: after one disk fails, an entire stripe side is considered degraded, making later failures riskier.

Rule: prefer RAID 10 for production-like designs.

RAID-Z1 / RAID-Z2 / RAID-Z3

RAID-Z1: similar one-parity protection. Best for small, non-critical pools.

RAID-Z2: two-parity protection. Common safer default for important ZFS storage.

RAID-Z3: three-parity protection. Useful for large vdevs or slow rebuild-risk environments.

Practical picker

Maximum speed, disposable data: RAID 0.

Simple safety: RAID 1.

Capacity + basic protection: RAID 5.

Large disks / safer rebuild: RAID 6 or RAID-Z2.

VM/database workload: RAID 10.
